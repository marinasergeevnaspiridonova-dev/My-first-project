# Мой первый сайт

Простая современная адаптивная главная страница на русском языке. Проект написан
на HTML, CSS и JavaScript без сборщика и сторонних JavaScript-зависимостей.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого сайт будет доступен по адресу `http://localhost:8000`.
